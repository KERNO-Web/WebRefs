# FACEMAIL — демо

Статическая демо-версия приватного почтового клиента FACEMAIL для портфолио.

Полностью работает в браузере: фронтенд реального интерфейса с вымышленными
письмами. Бэкенда, базы данных, почтового сервера, реальных пользователей и
секретов здесь нет — только то, что видит глаз.

Живой продукт: https://facemail.site

## Локально

```bash
npm install
npm run dev
```

Сборка: `npm run build` → `dist/`.
