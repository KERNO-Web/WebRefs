# NOCTIS — Wear the night

A fictional fragrance campaign built as a portfolio showpiece. React + TypeScript + Vite, Lenis smooth scroll,
a small WebGL shader for the hero portrait (liquid drift + cursor lens), scroll-driven film sequence.

Photography: Unsplash (free license), colour-graded and stored in `public/img` — see `unsplash-credits.txt`.
The bottle label was retouched out of the source photo; the NOCTIS mark is set in HTML on top.

```bash
npm install
npm run dev
```
