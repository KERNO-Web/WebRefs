# RANKED

Демо-витрина магазина игровых услуг: буст FACEIT / Premier / MMR / рангов, калибровка, тренировки.
CS2, Dota 2, Valorant, League of Legends, GTA Online. Только фронтенд: заказы и оплата не настоящие.

Изображения — официальные промо-материалы и скриншоты правообладателей (Valve, Riot Games, Rockstar Games), сохранены локально в `public/img` для демонстрации.

```bash
npm install
npm run dev
```
